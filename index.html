1. 연구 배경 및 AI 모델 비교 (ML vs BERT)

왜 머신러닝이 아닌 트랜스포머 기반 자연어 처리(BERT) 기법이 필요할까요?

머신러닝 기반 텍스트 분류

전통적 방식
  • 단어 및 표현 특징 분석으로 구동 방식이 간단함
  • 연산 자원이 적게 들고 빠른 학습 및 분류 속도
  • 한계: 단어 맥락, 반어법, 돌려 말하기의 의미 이해 불가능

트랜스포머 기반 자연어 처리 (BERT)

본 연구 채택
  • 문장 속 단어 간 관계 및 전체 맥락을 고려한 정교한 의미 파악
  • 복잡한 은유, 반어법, 웹툰 도메인 특유의 감정선 분석에 유리
  • 미세조정(Fine-Tuning): Ma 외(2019) 연구에 따라 웹툰 댓글 데이터를 추가 학습시켜 타겟 분야 성능 저하 문제 완전 극복

댓글 분석을 위한 4가지 핵심 속성 가공 체계

1. 문맥 및 의미

단순 단어가 아닌 전체 문장의 숨은 의도와 메인 주제를 추론

2. 감정 상태

독자의 태도를 긍정(Positive), 부정(Negative), 중립(Neutral)으로 분류

3. 공격성 수치

모욕, 인신공격 여부에 따라 높음(High) / 낮음(Low) 판단

4. 피드백 구체성

작화, 연출, 개연성 등 구체적 지적 여부(높음/낮음) 판별

5. GitHub Pages 배포 안내 (Deployment Guide)

본 대시보드 페이지를 깃허브에 쉽게 배포하는 단계별 가이드입니다.

1

파일 저장

이 소스코드를 소스 파일 최상위 경로에 index.html로 저장합니다.

2

저장소 커밋

git add index.html 및 git push origin main 명령어를 통해 업로드합니다.

3

Pages 설정

GitHub 저장소의 Settings → Pages 메뉴로 이동합니다.

4

배포 완료

Build and deployment에서 Branch: main / root 선택 후 Save를 클릭하면 대시보드가 라이브 호스팅됩니다.

Git Terminal Commands 
git add index.html
git commit -m "Feat: Add Webtoon-Comment-BERT interactive web dashboard"
git branch -M main
git push -u origin main
